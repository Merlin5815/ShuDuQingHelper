# 数独辅助 (Sudoku Helper)

一个面向安卓数独游戏的**悬浮窗辅助工具**。通过无障碍服务模拟点击 + MediaProjection 截屏识别，自动完成数独填写与候选剔除。

无需 root，无需电脑连接，纯手机端运行。

---

## 功能特性

- **网格/数盘自动检测**：白色连通域自动定位 9×9 棋盘边界 + 下方左填数盘/右候选盘
- **链式内存推演**：全屏识别一次建模型，链式双击期间仅截单格小图验证，零全屏识别高速填充
- **4 档自动填充**：
  - **一键填充**：全自动，依次执行 裸单双击 → 隐式唯一 → 数对剔除 → 试推反证，直到填满或无解
  - **双击单候选**：只做"格内只剩 1 个候选"的双击填入
  - **隐式唯一**：只做"某数在某行/列/宫只此一位"的填入（点格 + 左盘）
  - **数对剔除**：只做"显性数对/三链数/四链数"的候选剔除（点格 + 右盘）
- **提示功能**：不知道下一步时点"提示"，输出主建议 + 理由 + 操作指引，不执行任何点击
- **安全门**：候选自洽校验（每行/列/宫候选并集大小 == 9 - 已填格数），识别有幻影/漏识时自动拦截
- **试推反证**：假设候选成立 → 全规则传播 → DFS 检验全盘无解则剔除，可破任意残局
- **81 格自动结束**：全填满后自动停止，无需手动点停止
- **暂停/继续**：迷你控制栏，仅在动作边界挂起，不打断原子点击序列
- **日志系统**：UTF-8 文件日志，可分享到微信/QQ，无乱码

## 系统要求

- **Android 7.0 (API 24) 及以上**
- 三项权限（App 内引导开启）：
  - 无障碍服务（模拟点击）
  - 悬浮窗权限（显示辅助面板）
  - 屏幕录制（截屏识别，建议选择整个屏幕）

## 编译方法

```bash
cd android-app
./gradlew assembleDebug

```

## 使用流程

1. 安装后打开 App，按主界面教程依次开启三项权限
2. 点"④ 启动悬浮窗"切到后台，露出数独游戏
3. 在悬浮窗点"校准"自动检测棋盘网格
4. 点"数盘"自动检测下方左填数盘 + 右候选盘
5. 点"识别"查看当前盘面状态
6. 按需点"一键填充" / "双击单候选" / "隐式唯一" / "数对剔除"
7. 卡住时点"提示 (下一步)"看解题思路

> 完整使用教程内置于 App 主界面，新用户打开即可看到。

## 技术架构

| 模块                       | 说明                                                    |
| -------------------------- | ------------------------------------------------------- |
| MainActivity               | 权限申请、悬浮窗启动、后台任务调度                      |
| FloatingWindow             | 可拖动悬浮窗，校准/识别/填充/提示按钮，迷你控制栏       |
| SudokuAccessibilityService | 无障碍服务，封装点击/双击                               |
| ScreenCaptureService       | MediaProjection 前台服务，提供截屏 Bitmap               |
| GridDetector               | 白色连通域自动检测 9×9 网格边界                         |
| PadDetector                | 白色连通域检测左填数盘 + 右候选盘                       |
| SudokuDetector             | 单格像素分析：黑字/青字/灰候选识别，固定 3×3 分区判数字 |
| SudokuSolver               | 内存推演模型：裸单/隐式唯一/摒除/显性子集/试推反证      |

### 识别原理

- 三种墨迹用亮度+饱和度区分：黑字（已填）、青字（玩家填入）、灰候选
- 候选小字严格按数字键盘 3×3 位置摆放，用固定分区边界判数字（非最近邻）
- 自洽安全门：每个行/列/宫候选并集大小 == 9 - 已填格数，识别错误双向破坏等式

### 推演优先级

```
裸单候选(双击) > 隐式唯一(点格+左盘) > 宫/行列摒除 > 显性子集 > 试推反证
```

试推法作为通用兜底，可保证破任意残局（X-Wing/XY-Wing 等高级技巧的严格子集）。
